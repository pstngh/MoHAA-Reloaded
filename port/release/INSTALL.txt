MoHAA Reloaded (Metal), version @VERSION@: OpenMoHAA native on Apple Silicon
======================================================================

A native Metal port of OpenMoHAA for Apple Silicon Macs (M1 or later) with macOS 26 or later. It plays
Medal of Honor: Allied Assault, Spearhead and Breakthrough on existing MOHAA and OpenMoHAA servers.
The game data is not included: you need your own retail copy.

https://github.com/pstngh/MoHAA-Reloaded


Install
-------

1. Unzip the download (double-click it). You get the folder this file is in.

2. Clear the download's quarantine, once. This build is signed ad hoc and not notarized by Apple, so
   macOS refuses to run the downloaded files until the quarantine is cleared. Open Terminal, type the
   line below followed by a space, drag this folder onto the Terminal window (that types its path),
   and press Return:

     xattr -dr com.apple.quarantine

   For example: xattr -dr com.apple.quarantine ~/Downloads/openmohaa-metal-@VERSION@-macos-arm64

   "Open Anyway" in System Settings > Privacy & Security is not enough for this game: macOS then runs
   the app from a temporary read-only copy, where it can't find your game data. The game then stops
   and shows the line to run, with your folder's path.

3. Find your MOHAA game folder: the folder that holds main/ (Pak0.pk3 to Pak6.pk3), plus mainta/ for
   Spearhead and maintt/ for Breakthrough. From the GOG installer you can get it with innoextract:
   https://github.com/pstngh/MoHAA-Reloaded/blob/metal/docs/markdown/01-intro/01-installation.md#linux-and-macos-users

4. Copy openmohaa.app and mohlauncher.app into the game folder, next to main/. The game reads its data
   from the folder that holds the app; game.dylib and cgame.dylib are inside the app (any left beside it
   by an earlier version aren't used: you can delete them). (If you copied them before step 2, run the
   step 2 command on the game folder instead.)

5. Start mohlauncher.app, MoHAA Launcher: it starts Allied Assault, Spearhead or Breakthrough, at the
   main menu (Single Player) or onto a server (Connect), with your name, the server's passwords, the
   crosshair, and the resolution and display mode. The servers you join are kept in its list. If the
   game folder is on an external drive (or in a folder macOS protects, such as Documents or Desktop),
   macOS asks whether the launcher and the game may access files there: click Allow. It asks again after each update (the permission belongs to that
   exact build), as step 2 is needed again.

   openmohaa.app starts directly too: Allied Assault by default. For Spearhead or Breakthrough, open
   Terminal in the game folder and run one of:

     open openmohaa.app --args +set com_target_game 1
     open openmohaa.app --args +set com_target_game 2

Configs, saves, screenshots, demos and logs go into the game folder, as in the original game
(main/configs/omconfig.cfg and main/screenshots/ for Allied Assault). Started from MoHAA Launcher,
everything goes there, the launcher's mohlauncher.json (your servers and their passwords) too, and a
config kept in ~/Library/Application Support/openmohaa/ is copied over once. Started otherwise, the
game uses ~/Library/Application Support/openmohaa/ if the game folder isn't writable. Settings that OpenMoHAA saved there before are
read on the first start and then saved into the game folder, unless the game folder already holds a
main/configs/omconfig.cfg from another OpenMoHAA build: that one wins (delete it to keep the others).
The game sends servers no GUID (it keeps no qkey file), as the original game's clients don't. The
settings that matter for this port (cl_movefps, com_maxfps, the display modes, in_mouseRaw,
m_filter) are described in the README:
https://github.com/pstngh/MoHAA-Reloaded/blob/metal/README.md#settings-that-matter-here
